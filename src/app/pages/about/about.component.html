About quizmastr

quizmastr is a free, fast-paced trivia quiz game. There's no account to create and nothing to install - pick a name, pick a mode, and you're answering questions within a few seconds.

Single Player

Solo mode gives you 30 seconds on the clock and a run of general-knowledge questions covering film, history, science, video games, music and more. Answer as many as you can before time runs out - each correct answer adds a point, and your final score is shown (and shareable) the moment the timer hits zero.

Multiplayer

Playing with friends takes three steps:

  • 1 One player hosts a quiz and picks a difficulty. This generates a short quiz code and link.
  • 2 Everyone else joins using that code (or just clicks the shared link) and picks a name.
  • 3 The host starts the quiz. Everyone gets the same 30-second run of questions and answers at their own pace - a live leaderboard shows how everyone's doing, and there's an option to vote for an instant rematch once the round ends.

Up to 8 players can join a single quiz.

Where the questions come from

Every question comes from Open Trivia DB, a free, community-maintained trivia database. We don't write or edit the questions ourselves, so if one looks wrong, that's where to report it.

Keeping it running

quizmastr is a small, independent project with no subscriptions or paywalls. If you'd like to support it directly, there's a link at the bottom of every page - otherwise, just enjoy the quiz.
